# Kumo Documentation

Welcome to the Kumo documentation. Kumo is a high-performance, security-focused package manager for the Node.js ecosystem, written in Rust.

## CLI Commands Reference

- [Kumo CLI](kumo.md) - Main command for managing dependencies, project security, and maintenance.
- [Security & Config](security.md) - How Kumo protects your project and how to customize policies.
- [KX (Kumo Execute)](kx.md) - Run binaries from local dependencies or execute remote packages.

## Getting Started

To get started with Kumo, you can install it using our installation script:

```bash
# On Unix-like systems
curl -fsSL https://raw.githubusercontent.com/jmaxdev/Kumo/main/install.sh | sh
```

For more information on installation, see the main [README.md](../README.md).
